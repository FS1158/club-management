# 清华附中初中社团管理系统

## 一、功能概览

### 双角色系统
- **管理员**：全局控制，管理所有社团、调配学生、导出全部考勤报表
- **社团老师**：仅管理自己社团，编辑名称、导入名单、记录考勤

### 核心功能
- **社团管理**：创建/编辑40+社团，设置名称、指导老师、独立PIN码
- **学生名单导入**：粘贴"学号 姓名"文本即可批量导入，支持多种分隔格式
- **考勤打卡**：按日期创建考勤，标记"到勤/迟到/缺席"，支持全勤/全缺/清空快捷操作
- **实时同步**：所有修改实时同步到所有在线设备（SSE技术），无需刷新
- **学生调配**：管理员可将学生从一个社团调换到另一个社团
- **考勤报表导出**：
  - 管理员一键导出**全部社团**考勤汇总（CSV）
  - 导出单个社团考勤明细（CSV）
  - CSV可直接用Excel打开
- **全局学生搜索**：输入姓名或学号，快速查找学生在哪个社团
- **考勤界面搜索**：在考勤打卡页面按姓名/学号快速筛选学生
- **清华紫主题 + 校徽**：界面采用清华紫配色，首页展示清华附中校徽
- **移动端优化**：手机浏览器直接打开，可添加到桌面像APP一样使用（PWA）

## 四、正式部署（让所有老师都能访问）

### 方案A：Railway（推荐，免费额度够用）

1. **注册 Railway**
   - 访问 https://railway.app
   - 用 GitHub 账号登录

2. **上传代码到 GitHub**
   - 在 GitHub 创建一个新仓库（如 `club-management`）
   - 将 `club-management` 文件夹内容上传

3. **在 Railway 部署**
   - 点击 "New Project" → "Deploy from GitHub repo"
   - 选择你的仓库
   - Railway 会自动检测 Node.js 项目并安装依赖
   - 设置端口环境变量：`PORT=3000`
   - 部署完成后会得到一个公网URL，如 `https://club-management.up.railway.app`

4. **修改管理员密码**
   - 部署后，首次登录管理员账号
   - 在设置中修改管理员密码
   - 将公网URL分享给所有社团老师

### 方案B：Render（同样免费）

1. 访问 https://render.com 注册
2. "New" → "Web Service" → 连接 GitHub 仓库
3. 设置：
   - Build Command: `npm install`
   - Start Command: `node server.js`
4. 部署后获得公网URL

### 方案C：CloudStudio（云端沙箱）

直接使用 WorkBuddy 的云端部署功能，一键部署到 CloudStudio 沙箱。

## 五、使用流程

### 管理员操作指南

#### 1. 登录
- 打开APP，选择"管理员登录"
- 输入管理员密码（默认 `admin123`）

#### 2. 查看仪表盘
- 登录后显示总览：社团总数、学生总数、考勤日期数、到勤率
- 快速了解整体考勤情况

#### 3. 创建社团
- 在社团列表页点击"新建社团"
- 输入社团名称、指导老师、4位PIN码
- 点击创建

#### 4. 调配学生
- 进入任意社团 → 编辑模式
- 可将学生调换到其他社团
- 选择目标社团后确认

#### 5. 导出考勤报表
- **导出全部社团**：在管理员面板点击"导出全部考勤"
  - 生成CSV文件，包含所有社团、所有学生、所有日期的考勤
  - 可直接用Excel打开
- **导出单个社团**：进入社团详情页 → 点击"导出"按钮
  - 生成该社团的考勤明细CSV

#### 6. 查找学生所在社团
- 点击顶部搜索图标，或登录页"查找学生所在社团"
- 输入学生姓名或学号
- 系统会显示该学生所在社团，点击可进入社团详情

#### 7. 修改设置
- 在设置中可修改管理员密码
- 可查看系统信息

---

### 社团老师操作指南

#### 1. 登录
- 打开APP，选择"教师登录"
- 选择自己的社团
- 输入4位PIN码

#### 2. 编辑社团信息
- 进入社团 → 点击编辑图标
- 可修改社团名称、指导老师
- 注意：只能编辑自己社团

#### 3. 导入学生名单
- 在编辑模式下找到"导入学生名单"
- 从选课系统复制学生数据
- 粘贴到文本框，格式示例：
  ```
  2024001 张三
  2024002 李四
  2024003 王五
  ```
- 点击"导入名单"

#### 4. 添加考勤日期
- 返回社团详情页
- 点击"添加日期"
- 选择日期（默认今天）

#### 5. 考勤打卡
- 点击对应日期进入考勤页面
- 在搜索框输入姓名或学号，可快速找到学生
- 对每个学生点击状态：
  - **到**（绿色）= 到勤
  - **迟**（橙色）= 迟到
  - **缺**（红色）= 缺席
- 再次点击相同状态 = 取消标记
- 快捷操作：全勤 / 全缺 / 清空

#### 6. 查找学生
- 点击顶部搜索图标
- 输入学生姓名或学号，可查找该学生在哪个社团

#### 7. 查看考勤统计
- 社团详情页显示每个日期的考勤摘要
- 到勤/迟到/缺席/未标记人数一目了然
- 其他老师打开同一社团实时看到更新

## 六、技术架构

| 组件 | 技术方案 |
|------|---------|
| 前端 | HTML + CSS + 原生JS（移动端PWA） |
| 后端 | Node.js + Express |
| 数据存储 | JSON文件（轻量级，适合中小规模） |
| 实时同步 | SSE（Server-Sent Events） |
| 认证 | Token-based（管理员密码 / 社团PIN码） |
| 导出 | CSV格式（UTF-8 BOM，Excel兼容） |
| 部署 | Railway / Render / CloudStudio |

## 八、常见问题

**Q: 管理员密码忘了怎么办？**
A: 编辑服务器上的 `server.js` 文件，找到 `DEFAULT_SETTINGS` 中的 `adminPassword` 字段，修改后重启服务器。

**Q: 老师忘记自己社团的PIN码怎么办？**
A: 管理员登录后，在社团编辑页面可以查看和重置PIN码。

**Q: 40个社团够用吗？**
A: 完全够用，系统支持无限数量社团。

**Q: 数据会丢失吗？**
A: 数据存储在服务器端的 data.json 文件中。建议定期备份。如果部署在 Railway/Render，数据会持久化在容器存储中。

**Q: 多人同时编辑会冲突吗？**
A: 每次修改都会实时同步到所有打开的设备。如果两人同时修改同一学生的考勤，后修改的会覆盖先修改的。

**Q: 导出的CSV打开乱码怎么办？**
A: CSV已添加UTF-8 BOM头，Excel应能正确识别。如仍乱码，用Excel打开时选择"数据→从文本/CSV"，选择UTF-8编码。

**Q: 可以离线使用吗？**
A: 需要网络连接。考勤数据存储在服务器端，实时同步依赖网络。
